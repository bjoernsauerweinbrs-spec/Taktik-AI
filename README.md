# ⚽ Coach Toni 2.0 – Elite Taktik-Plattform

Willkommen beim digitalen Co-Trainer! Diese Plattform kombiniert brasilianisches Technik-Flair mit modernster KI-Analyse.

## 🚀 Kern-Features
* **Interaktives Taktikboard:** Verschiebe Spieler (Blau) per Drag-and-Drop, während Toni die roten Spieler taktisch positioniert.
* **KI-Coach Toni:** Ein absoluter Fachmann, der Trainingseinheiten und Spielsituationen in Echtzeit analysiert.
* **Kader-Management:** Dynamische Anwesenheitsliste und automatische Synchronisation der Rückennummern.
* **Export-Funktion:** Erstelle professionelle Trainingspläne direkt als PDF.

## 🛠 Technik-Stack
* **Frontend:** HTML5, CSS3 (Modern UI mit Glassmorphism-Effekten)
* **Logik:** Modularer JavaScript-Kern (`js/board.js`, `js/chat.js`, `js/logic.js`)
* **Intelligenz:** Anbindung an High-Performance Sprachmodelle (Groq API)

## 📋 Anleitung
1. System mit dem Trainer-Passwort initialisieren.
2. Kader in der Whiteboard-Ansicht abgleichen.
3. Trainingsphasen über die Playlist steuern oder Toni per Sprachbefehl (Mikrofon) um Rat fragen.
